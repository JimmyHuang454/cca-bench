# wifi6_ampdu_burst

Wi-Fi 6 CSMA/CA 信道争用 + A-MPDU TXOP 随机聚合突发（平均 ~36 Mbps，静默间隙 5–16 ms）。

## 参数说明

- 上行容量：每次传输前经历 5–16 ms 随机静默争用间隙，随后在 1–2 ms TXOP 内突发释放多个数据包（均值约 36 Mbps）。
- 上下行基础延迟：各 8 ms（固定基础 RTT 16 ms，无外加传播延迟抖动，完全由 MAC 聚合突发产生 $j$ 与 $k=c/\mu$）。
- 考察重点：检验算法在纯 MAC 突发聚合链路下抑制饿死并控制排队的能力。

场景持续 60 秒，区间左闭右开。TCP 数据走上行（`up.txt`），ACK 走下行（`down.txt`）；基础 RTT 为上下行单向基础延迟之和。容量和延迟具体时间点以本目录中的 lines 文件为准。
