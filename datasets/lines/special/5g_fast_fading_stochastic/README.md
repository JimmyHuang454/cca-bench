# 5g_fast_fading_stochastic

5G 快衰落随机服务波动（纯 Kingman 扩散 $k=c/\mu>0$，无静态延迟抖动 $j=0$）。

## 参数说明

- 上行容量：每 25 ms 按两态马尔可夫链在强信号（40–56 Mbps）与深衰落（6–14 Mbps）间快速随机切换（均速约 30 Mbps）。
- 延迟：上下行基础延迟恒定各 10 ms（基础 RTT 20 ms，完全无外加延迟抖动）。
- 考察重点：隔离验证方案 B 多尺度队列扩散对随机服务色散 $k=c/\mu$ 的估计——原版 Copa 队列过浅错失高速窗口，BBR/CUBIC 在衰落槽产生高尾延迟，Copa-Auto v3 命中理论最优 $d_q^*=\sqrt{k R_0}$。

场景持续 60 秒，区间左闭右开。数据保存在 `line.csv` 中：TCP 数据走上行（`up_cap`），ACK 走下行（`down_cap`）；基础 RTT 为上下行单向基础延迟之和。
