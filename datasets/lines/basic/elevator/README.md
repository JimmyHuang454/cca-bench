# elevator

模拟进入电梯、弱连接、短暂断连和走出电梯；这是人为构造的场景，不是实测轨迹。

| 时间（s） | 上行容量（Mbps） | 下行容量（Mbps） | 上行单向基础延迟（ms） | 下行单向基础延迟（ms） |
| --------- | ---------------: | ---------------: | ---------------------: | ---------------------: |
| 0–15      |               20 |               50 |                     20 |                     20 |
| 15–20     |                2 |                5 |                     50 |                     50 |
| 20–25     |                0 |                0 |                     50 |                     50 |
| 25–40     |                1 |                3 |                     80 |                     80 |
| 40–45     |                5 |               15 |                     40 |                     40 |
| 45–60     |               20 |               50 |                     20 |                     20 |

场景持续 60 秒，区间左闭右开。TCP 数据走上行，ACK 走下行；基础 RTT 为两方向单向基础延迟之和。

Bulk 在场景结束时停止；workload 超过场景时长时循环回放。容量和延迟文件的具体时间点以本目录中的 lines 文件为准。
